**Components**

**Splunk Forwarder**: Agent installed on the endpoint to be monitored. Collects and sends log data to splunk.

**Splunk Indexer**: Parses and normalizes data into field-value pairs, categorizes it, and stores the results as events, making the processed data east to search and analyze.

**Search Head**: The place withing Search & Reporting where users can search the indexed logs. Searches are made using SPL (Search Processing Language). When a user performs a search the request is sent to the indexer and relevant events are returned as field-value pairs. The search head also allows transforming the data into visual representations (charts).
